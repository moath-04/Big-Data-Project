
# Emergency Response Time Prediction

## Project Overview
This project aims to predict emergency response times
for traffic accidents using traffic, weather,and
road-related data.

## Objectives
- Explore and clean the dataset.
- Analyze factors associated with emergency response times.
- Visualize key patterns in the data.
- Train and evaluate a Random Forest regression model.

## Dataset
The project uses a synthetic traffic dataset containing
approximately 200,000 records and 29 columns.

## Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
